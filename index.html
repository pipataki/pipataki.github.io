VoiceController

Control del ordenador por voz, pensado para la accesibilidad. Hablas, y el ordenador hace: mover el puntero, pulsar, escribir al dictado, manejar ventanas, abrir carpetas.

  • Funciona en Linux (KDE Plasma) y en Windows, con una app para Android que hace de micrófono y de mando.
  • El reconocimiento de voz va en tu propio ordenador: tu voz no se envía a ningún sitio.
  • Es software libre, con licencia LGPLv3.

Está en desarrollo: versión 0.2.4 (pre-alpha).

Descarga

  • Paquete de instalación 0.2.4 (zip, 4,9 MB), para Linux y Windows. Lleva dentro la app de Android y el manual.
  • App de Android (apk), para instalarla directamente en el móvil.
  • Manual en PDF, que se puede leer con lector de pantalla: en español o en inglés.

Todas las versiones y el código fuente están en GitHub.

In English

VoiceController lets you control your computer by voice, built with accessibility in mind. It runs on Linux and Windows, with an Android app as a remote microphone. Speech recognition stays on your own computer. Free software (LGPLv3), currently in development (0.2.4, pre-alpha). Download the installation package, the Android app or the manual in English. The source code is on GitHub.
